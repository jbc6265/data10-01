# data10-01 · 굴착기 카운터웨이트 프레스 예지보전

프레스 로그(타수·가동 시간·전류·전압·온도·진동)를 가져와 2초 센서 값의 ±3σ 실시간 관리도, 금형별 타수 집계·교체 예정일, 오버홀 알림, 통계 기준 이상 감지, 월별 프레스 종류별 타수 보고서를 만드는 브라우저 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 조병철 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-10-20) · 2차 반영 — 2초 로그·±3σ 관리도 (2026-10-21) — https://aebonlee.github.io/data10-01/ |
| 다음 개발 | 2단계 — 실제 로그·고장/교체 이력으로 기준 맞추기, 협력사 공유·로그인(Supabase), 알림 보내기, 학습형 예지 |

> 1단계는 패들릿 게시물·댓글만으로, 2차는 수강생이 보낸 로그 샘플(2초 간격 모의 데이터)과 「±3σ 관리선」 요청으로 만들었습니다. 리포의 샘플은 모두 같은 형식으로 새로 만든 **가상 값**입니다(수강생 파일은 두지 않음).

## 실행 방법

이 저장소는 `aebonlee/data10-01`의 2차 반영을 병합한 개인 개발본입니다. HD현대 CI 색상과 `samples/프레스로그_2초간격_2시간.csv`를 유지합니다. 아래 온라인 주소는 원본 프로젝트의 배포 주소이며 이 저장소의 배포 주소가 아닙니다.

운영 방향(2026-10-21): 파일 업로드에 머무르지 않고 PLC·OPC UA·MQTT 등 설비 데이터 직접 연결을 목표로 합니다. 현재 확보된 자료는 모의 데이터뿐이며 실제 연결 방식과 정상 기준 구간은 아직 확정하지 않았습니다. 이 버전에 설비 자동 수집 기능이 구현된 것은 아닙니다.

**온라인에서 바로 보기: https://aebonlee.github.io/data10-01/**

**2차 — 2초 센서 로그**: 설비가 2초마다 보낸 로그 CSV(일자에 초까지)를 그대로 넣으면 「실시간 관리도」로 갑니다. 「2초 로그 샘플(4대 × 3일)」 버튼으로 먼저 둘러볼 수 있습니다 — P2 전류 상승(±3σ 이탈), P3 20분 정지·진동 튐, P4 금형 교체(금형 타수 0), P1 기록 끊김을 심어 두었습니다.

처음 열면 「데이터 가져오기」 화면입니다. **「샘플 90일로 시작」** 을 누르면 가상 로그 4개 파일(7·8·9월 엑셀, 10월 CSV)과 설비·금형 기준표가 들어가고 대시보드로 넘어갑니다. 일부러 심어 둔 세 가지가 바로 보입니다 — 금형 M-05 수명 임박(주의), P2 마지막 2주 전류·온도 상승(점검 필요), P4 오버홀 주기 지남(점검 필요).
실제로 쓸 때는 로그 엑셀·CSV 를 여러 개 한꺼번에 넣고, 설정에서 금형 수명 기준 타수와 오버홀 주기를 넣습니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS).

**외부 망·협력사 접속** — 위 주소는 회사 밖 어디서나 열립니다. 다만 1단계는 데이터를 **각자의 브라우저에만** 저장하므로, 협력사가 같은 주소로 들어와도 서로의 데이터는 보이지 않습니다(각자 자기 로그를 넣어 씀, 백업 JSON·기준표 엑셀로 주고받기는 가능). 같은 데이터를 함께 보는 협력사 공유·로그인은 2단계(Supabase)에서 만듭니다.

| 화면 | 하는 일 |
|---|---|
| 실시간 관리도 (2차) | 2초 센서 로그 — 프레스·금형·보는 구간(전체·최근 10분~하루·기간 지정)·묶어 보기(2초 원값·1분·5분 평균), 채널별 마지막 값 카드, 전류·전압·온도·진동 Shewhart 관리도(중심선·±3σ 관리선·±2σ 경고선·이탈점 빨간 점, 많으면 칸 평균·최소·최대로 줄이되 이탈점은 그대로), 기준 구간(처음 N개·기간)·σ 방식(표본 표준편차·MR̄/1.128) 선택, 규칙(1점 ±3σ + 선택: 연속 9점 한쪽·연속 6점 증가/감소·3점 중 2점 ±2σ), 타수/시간·10초 1타 기준 대비·시간 가동률·정지 구간·기록 끊김·금형 리셋, 이탈 목록·엑셀 |
| 대시보드 | 2초 센서 마지막 값(프레스별, 최근 1시간 이탈·가동/정지) · 프레스별 상태 카드(정상·주의·점검 필요와 근거 — 이상 감지·오버홀·최근 쓴 금형 수명 가운데 가장 나쁜 것), 최근 7일 타수, 채널별 평소 대비 최근 값, 금형 수명 사용률 막대, 다가오는 정비 일정(45일) |
| 데이터 가져오기 | 2초 로그 CSV 는 앞부분으로 가려 4MB 조각으로 나눠 읽기(큰 파일도 화면 멈춤 없이, IndexedDB 저장, 하루 묶음으로 기존 판정에 이어 붙임) · 엑셀·CSV 여러 개·폴더째 · 제목 줄 아래 머리행 자동 인식 · 열 연결 확인/수정(같은 머리행 파일에 함께 적용) · 단위 괄호 읽기(가동 시간(분) → 시간) · CSV UTF-8/CP949 자동 판별 · 같은 행(일자+시각+프레스+금형) 중복 제거 · 행 점검 알림 · 타수 계산 출처와 「타수 합 ≠ 누적 차이」 점검 |
| ① 금형 타수·교체 | 금형마다 사용 타수(시작 시점 사용 + 사용 시작일부터 로그)·사용률·남은 타수·최근 14일 일평균·교체 예정일, 교체 기록 버튼, 금형별 월 타수 집계, 엑셀 |
| ② 오버홀 알림 | 마지막 오버홀부터 타수·날수를 주기(타수·일수, 먼저 닿는 쪽)와 비교, 예정일·지난 날수, 완료 기록 버튼 |
| ③ 이상 감지 | 프레스 × 채널 한눈 표, 채널마다 최근 14일을 직전 42일 기준선(중앙값·MAD)과 비교 — ±3σ 를 가동일 3일 연속 넘으면 점검 필요, ±2σ 3일 연속이나 ±3σ 2일이면 주의. 근거 숫자(기준선·관리한계·연속 날짜·추세)와 관리도 그래프 |
| ④ 월별 타수 보고서 | 달을 골라 프레스 종류별·프레스별·금형별 타수, 월별 추이(그래프·표), 현재 알림, AI 의견 — 엑셀·인쇄(PDF) |
| ⑤ AI 분석 | 계산된 사실만 담은 프롬프트 — **프레스·금형 이름은 「설비1」「금형1」 별칭으로 가림(기본)**, 대응표는 이 PC 에만, 답의 별칭은 되돌림(복사·붙여 넣기, 선택: 본인 키로 OpenAI 호환 서버에 자동 보내기) |
| 설정 | 설비 기준표(종류·오버홀 주기·마지막 오버홀), 금형 기준표(수명 기준 타수·사용 시작일·시작 시점 사용 타수), 기준표 엑셀 주고받기, 판정 기준, AI 연결, JSON 백업 |

## 1단계 구현 범위

| 요청 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 프레스 이상 감지 알림 | 완료(통계 기준) | 평소 대비 벗어남을 「주의·점검 필요」로 표시. 고장 이력으로 배우는 예지는 2단계 |
| 2초 센서 값 ±3σ 관리선 (2차 요청) | 완료 | 실시간 관리도·마지막 값·이탈 목록. 「실시간」은 파일을 넣을 때마다 갱신, 설비에서 바로 받기는 2단계 |
| 금형별 타수 집계 | 완료 | 금형별 사용 타수·월 타수 |
| 금형 교체주기 알림 | 완료 | 수명 기준 타수는 설정에서 입력(실제 기준 확인 필요) |
| 프레스 정기 오버홀 알림 | 완료 | 타수·일수 주기 둘 다 |
| 월별 프레스 종류별 타수 보고서 | 완료 | 엑셀·인쇄 |
| 협력사 접속(외부 망) | 일부 | 웹 주소는 외부에서 열림. 데이터 공유·로그인은 2단계 |
| 알림 보내기(메일·메신저) | 2단계 | 지금은 화면 표시 |
